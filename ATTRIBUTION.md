# Attribution

This kit was built after analyzing the HTML Effectiveness unknowns reference pages and extracting reusable design principles for Warm Editorial UI artifacts.

The source reference files include this notice:

`Copyright 2026 Anthropic PBC · SPDX-License-Identifier: Apache-2.0`

The bundled examples in this repository are adapted/reconstructed artifacts that preserve the observed design grammar:

- Warm ivory paper background.
- White report cards.
- Mono labels.
- Serif editorial titles.
- Clay and olive semantic accents.
- Inline SVG thumbnail grammar.
- Subtle hover states.

They are not intended to be a verbatim mirror of the original reference pages.
