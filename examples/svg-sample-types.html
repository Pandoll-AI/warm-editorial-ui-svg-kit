Applied SVG kit · html-effectiveness unknowns

10 SVG sample types for drawing new unknowns.

원본의 SVG 문법을 응용해 목적별로 다시 그린 샘플입니다. 각 SVG는 복사해서 새 artifact 카드, 설명 페이지, 설계 하니스에 바로 응용할 수 있도록 의도와 스타일링 설명을 같이 붙였습니다.

Canvas

모든 thumbnail은 viewBox="0 0 120 80" 기준입니다.

Primitive

rect, line, circle, 간단한 path만 씁니다.

Unknown

불확실성은 clay dashed line, 빈 원, 끊긴 edge로 표현합니다.

Hover

path morph 없이 fill swap, card lift, arrow nudge만 씁니다.

01Audit

Blindspot radar

의도: 문서나 코드에서 아직 보지 못한 위험 지점을 찾는 카드.

문서 본문은 회색 라인으로, 발견된 단서는 clay 점으로, 아직 검증되지 않은 영역은 dashed circle로 표현합니다.

Style: document + clay marker + dashed unknown target →
02Choice

Decision fork

의도: 구현 전에 선택지가 갈라지는 지점을 표시.

확정 경로는 gray/olive, 다시 물어봐야 하는 경로는 clay dashed curve로 표시합니다.

Style: branching connector + dashed unresolved branch →
03Proof

Verification rail

의도: 작업 단계와 검증 상태를 한 번에 보여주는 rail.

완료는 olive, 현재 실패/위험은 clay, 아직 남은 단계는 dashed circle로 구분합니다.

Style: state dots + proof card + deferred dashed baseline →
04Port

Reference parity

의도: 원본 구현과 포팅 구현의 의미가 맞는지 비교.

두 문서를 나란히 놓고, 차이가 있는 줄은 clay/dashed로 연결합니다. 통과한 parity는 olive check로 닫습니다.

Style: paired pages + clay diff link + olive pass marker →
05Prompt

Prompt contract

의도: 최종 프롬프트나 작업 계약의 필수 조건을 표시.

문서 header, 좌측 clay rule, exit chip, dashed missing clause로 “아직 명시해야 할 조건”을 드러냅니다.

Style: prompt document + exit chip + missing-clause dash →
06Schema

Schema drift

의도: 테이블/데이터 모델의 drift 위험을 작게 압축.

matrix 구조는 gray grid, drift cell은 clay dashed interior, 영향 범위는 하단 dashed band로 표시합니다.

Style: table grid + highlighted drift cell + dashed impact band →
07Toolbar

Interaction toolbar

의도: 클릭 가능한 도구막대나 mock UI를 작은 SVG로 표현.

어두운 toolbar, clay active tool, swatch row, progress line을 조합해 실제 조작면을 암시합니다.

Style: slate toolbar + icon glyphs + swatches + progress marker →
08Pitch

Handoff pitch

의도: 리뷰어나 의사결정자에게 보여줄 buy-in artifact.

데모 영상 블록, 근거 라인, 승인 pill을 배치해 “설명 가능한 산출물”임을 보여줍니다.

Style: mini video + proof copy + approval pill →
09Quiz

Merge readiness quiz

의도: 내가 변경 내용을 실제로 이해했는지 확인하는 퀴즈.

상단 질문 카드, 아래 답변 row, pass/fail marker로 “검수 전 점검”의 느낌을 만듭니다.

Style: question block + answer rows + clay check path →
10Map

Unknown territory map

의도: map과 territory의 차이를 시각적으로 설명.

땅의 레이어는 territory, 작은 slate label은 현재 map, clay target은 아직 가보지 않은 unknown zone입니다.

Style: layered terrain + map label + dashed unknown zone →
