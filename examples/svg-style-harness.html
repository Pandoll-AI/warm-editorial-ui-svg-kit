SVG extraction harness

Tokenized thumbnails first. Bespoke scenes second.

This harness extracts the original unknowns page SVG grammar into a repeatable test surface: exact reference thumbnails, newly drawn samples, hover-force mode, and scene-style exceptions.

Observed SVG rules

Canvas

Index thumbnails use a fixed viewBox="0 0 120 80" inside a 132px tall warm thumb.

Primitives

Use mostly rect, line, circle, and simple path. Round corners via rx=2..7.

Stroke grammar

Default strokes are g500, 2.5px, no fill, round caps. Clay strokes mark action, unknown, or active paths.

Fill grammar

.wh and .oa are surface classes with stroke. .fl is passive fill and darkens on hover.

Dashes

.da uses 4 4 dashes for tentative, unknown, or secondary structures.

Hover

Hover does not morph paths. It changes card chrome, thumb background, fill tokens, file color, and arrow offset.

Bespoke scene layer

Scene-style SVG is not the same as the index thumbnails. It uses a 640x360 cinematic canvas, layered landscape paths, direct hex fills, opacity, and annotation strokes.
Tool/icon SVG uses currentColor-like glyph logic, sparse UI panels, direct fills, and enough geometry to read at thumbnail size.
